# EnterVRIME Debug 版

Debug 版与普通版功能相同，但会额外保留一个控制台窗口，适合在软件启动即退出、来不及点击“导出诊断包”时使用。

## 帮助我们定位问题

1. 双击 `EnterVRIME-Debug.exe`。
2. 按照能稳定触发问题的步骤操作一次。
3. 如果主窗口仍可使用，点击“导出诊断包”；也可从系统托盘选择“导出诊断包”。
4. 如果程序已经退出，打开 `%LOCALAPPDATA%\EnterVRIME\logs`，将最新的 `session-*.log` 和 `crash-*.log` 一并提供。
5. 提交问题时附上屏幕中的错误编号，例如 `E301` 或 `E401`。

诊断日志只记录程序状态、错误编号和异常调用栈，不记录聊天正文、拼音组合内容或输入法候选词。导出的 ZIP 还会自动隐藏用户目录与 Windows 用户名。
